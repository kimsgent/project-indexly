# Responsive static prototype

This is a deliberately self-contained **documentation prototype**, not a
production Indexly UI or a browser-accessible local service. It visualizes the
search-first direction from the parent investigation and uses only static data.

Open `index.html` directly in a browser. The prototype demonstrates:

- a dominant, scan-friendly results canvas with restrained file-type markers;
- workspace-specific enabled views and startup selection via **Manage views**;
- an inspector that can be closed and reopened, and resized with pointer or
  keyboard (arrow keys; Home/End); and
- a compact, labelled workspace-navigation drawer at tablet widths, a
  collapsed inspector by default there, and a full-width contextual inspector
  on narrow screens instead of squeezed desktop panes.

It is intentionally not evidence of a backend contract. The service, local
access, job, state, path, and parity requirements are in the parent documents:
[README](../README.md), [architecture](../architecture.md), and
[feature parity](../feature-parity.md).
