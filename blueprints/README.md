# Project-Indexly blueprints

This root-level directory contains implementation blueprints that need to be
easy for maintainers and agents to discover without searching inside the Python
package tree.

## Available blueprints

- [Indexly local web UI](local-web-ui/README.md) — candidate architecture,
  contracts, product scope, staged delivery, implementation status, validation,
  evidence map, machine-readable manifest, and static interaction prototype for
  a local browser interface over the existing Indexly engine.

Each blueprint defines its own authority order, status vocabulary, current-work
location, and approval gates. A blueprint describes intended behavior; consult
its implementation-status document before treating a capability as current.
